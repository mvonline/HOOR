# Windows 0.5.0-dev / 2026-11-05

User requested a new executable after the source-only development pass.
Version 0.5.0-dev is built separately under `builds/windows-0.5.0-dev`.
The earlier running game was not closed; its locked crash-handler file caused
the first build attempt to fail. A selectable build output path avoids that.
The earlier 0.4.3 release ZIP remains unchanged.

Unity licensing succeeded on this attempt. The previous source report's license
block is historical and no longer prevents this build.

## Verification

The final Windows player passed all five suites through `Tools/Check-Player.ps1`:

- Prologue: 15 locations, 51 tasks, evidence choices, held tools, water cycle,
  ski/rest branches, Persian objective coverage, scene saves and Chapter 1 handoff.
- Chapter 1: the full authored drive route and chapter transition checks.
- Camp: evidence, memory cargo interaction, save/resume and progression.
- Spine: Chapters 3–10, optional H05/H06 persistence and exact dawn outcomes.
- Intro: existing video playback and skip.

Logs are under `builds/checks/release-{prologue,chapter-one,campaign,spine,intro}`.
The first prologue run found a blocked night detour. Its right-side waypoint
now also clears the pale landmark stone; the rebuilt player passed.
Drive failures now log the position, target and last collision obstacle.

Unity reuses the launcher timestamp in incremental builds. The build script
now checks fresh gameplay assembly content and the build-completion marker,
instead of rejecting a successful build solely because the launcher is unchanged.

## Scope

The release includes the prior character, localization, music, optional mission,
menu and prologue source changes. It remains a development version, with unfinished
environment art, character likenesses, performances, voice recordings and optional
content. No five-hour duration or complete human navigation review is claimed.
Some hidden-window screen captures are black; these do not establish visual QA.
Automated progression passing does not prove a finished production game.

The portable package is `builds/releases/Rad-e-Hoor-0.5.0-dev-Windows.zip`.
Packaging verifies required player files, archive CRC and creates a SHA-256 file.
