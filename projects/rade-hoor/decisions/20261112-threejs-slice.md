# Local Three.js / Blender slice

Status: user-approved direction, 12 November 2026.

The user accepted Three.js + Blender for the existing laptop, with the same
ten-minute integrated gameplay target: walking, running, driving, camel riding,
shooting, a coherent layout, background and sky. This supersedes the immediate
Unreal migration proposal. The Unity project and all story/art sources remain
preserved. The ten-chapter campaign is not being silently reduced or declared
implemented by this standalone slice.

Current work is in `game/DesertSlice`, launched by `DesertSlice.cmd`. It is an
actual local browser game with local dependencies and assets. It is not a Unity
or Unreal executable. Its route is a proposed mechanics staging exercise, not
a replacement for the canonical 6.2 screenplay.

The first connected implementation includes all requested transport/control
categories, a finite-ammunition armed encounter, checkpoint recovery and a
delivery ending. Acceptance remains open for human control feel, camel/rider
animation quality, combat depth, ten-minute pacing and target-device sustained
performance. Automated route completion is evidence of connectivity only.

No new Suno generation or download credits were used. Existing user-supplied
music and credited models/surfaces were reused. The camel and sidearm were
authored in Blender and exported as portable GLB assets.
