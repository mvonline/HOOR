# کتابخانهٔ تصاویر کانسپت ردِ هور

۷۹ تصویر دوبعدیِ غیرتکراری برای مرور و ارجاع. این‌ها فایل اجرایی، مدل سه‌بعدی، مرحلهٔ بازی یا تأییدِ طرح نهایی نیستند. [سناریو و طراحی ۷.۰](../redesign/v7-20261121/README.md) مرجعِ روایت جاری است.

تصاویر پیش از بازنویسی ۷.۰ تولید شده‌اند؛ ظاهر قابل استفاده از تصمیم روایی جداست. هیولاهای هور، بهرام۸۲ساله، خودروهای مربوط به دورهای تکرار و پایانِ بیرونی، کاننِ این نسخه نیستند. تصویرِ آن‌ها فقط به‌عنوان سابقهٔ کانسپت نگهداری می‌شود. هیچ تصویر قدیمی خودکار به‌عنوان کاراکتر یا صحنهٔ نهاییِ نسخهٔ تازه معرفی نمی‌شود.

## فهرست و منشأ

- [فهرست جاری با اندازه، ابعاد و SHA-256](image-index.json): ۷۹ PNG؛ هفت کپیِ یکسانِ محلی و دموها در آن تحویل داده نمی‌شوند.
- [ثبت تاریخی تولید ۵۶ تصویر](completion-manifest.json)، [پرامپت‌های تاریخی](completion-plan.json) و [پرامپت‌های اولیه](prompts.json): برای منشأ و سابقه، نه مالکیتِ داستانِ ۷.۰.
- [مرجع شخصیت جاری](../redesign/v7-20261121/CHARACTERS_AND_DRAMA_FA.md)، [جهان و مأموریت‌ها](../redesign/v7-20261121/WORLD_AND_MISSIONS_FA.md) و [نقشه‌های جاری](../redesign/v7-20261121/maps/README_FA.md).
